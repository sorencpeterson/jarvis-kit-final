# Objection Column #4: "I need to think about the money"

Source: objections.md #9. Category: price.

---

"I need to think about the money."

Fair. Take the time.

Here's what's actually true while you're thinking: the price holds for 14 days,
then it gets requoted. That's not a pressure tactic, it's just how long a quote
stays accurate before costs shift.

The real question worth sitting with isn't "can I afford this." It's "what number
would make this a yes today." If you know that number, you already know your
answer. If you don't, that's the actual thing to think about.
