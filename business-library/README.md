# Business Library — [OWNER]

**Read this folder first before any marketing, copy, or GHL task.** It holds
everything you need to know about me, my business, and how I want things built, so
a request like "build a 10-part email + SMS sequence for agency owners with Offer X
in GHL" inherits all my context automatically.

## Files

- `business-profile.md` — who I am, what the business does, products/services
- `brand-voice.md` — tone, style rules, words to use / avoid, examples
- `icp-and-personas.md` — target customers, segments, pain points, language they use
- `offers.md` — current offers, pricing, hooks, guarantees
- `automation-preferences.md` — defaults for sequences (cadence, channel mix, CTAs, structure)
- `ghl-setup.md` — GoHighLevel account specifics, naming conventions, where things live

## How this grows

Whenever I share a new fact, preference, win, or correction, add it to the right
file (or create a new one). Keep entries concise and dated when relevant. Treat
this as a living memory — the more complete it is, the more "just handle it" works.
