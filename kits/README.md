# Kits

Filled-in working documents, not code. The skills in `../skills/` generate this
kind of material on demand; these are the versions that already exist, hard-won
and battle-tested. Read them, then make them yours.

Everything is tokenized (`[OWNER]`, `[SALARY_ANCHOR]`, `[STANDARD_SITE]`...).
Replace the tokens before anything goes to a real person.

---

## `job-hunt/` — getting hired

**Start with `PRECISION-10-SPRINT.md`.** It is the most valuable file here and it
cost real pain to learn: 135 applications sent in one 55-hour burst produced zero
interviews. Volume without aim. The sprint is the correction: ten tailored
applications a day beats a hundred sprayed, with the profile fixed first and the
covers A/B tested. If you read one thing, read that.

| File | What it is |
|---|---|
| `PRECISION-10-SPRINT.md` | The one-hour-a-day execution loop. Read first |
| `MASTER-RESUME.md` | ATS-safe resume structure. Single column, real keywords, quantified bullets, no tables or graphics (they break parsers) |
| `LINKEDIN-REWRITE.md` | Headline and About that recruiters actually search |
| `COVER-LETTERS.md` | Two cover versions to A/B, plus how to swap the hook per role |
| `ANSWER-BANK.md` | Answers to the custom questions that show up on every application |
| `INTERVIEW-PREP.md` | STAR stories and the hard questions |
| `APPLICATION-PACKETS.md` | Assembling a full packet per role |

The resume and answer bank were written for a marketing/ops profile. The
**structure** transfers to any field; the content does not. Rewrite the substance,
keep the format.

## `client-work/` — getting paid

Templates for freelance and agency work. Send-ready once you swap the tokens.

| File | What it is |
|---|---|
| `templates-bundle.md` | The core set with `{{merge_fields}}`: care plan, follow-ups, asks |
| `care-plan-email.md` | The recurring-revenue pitch, sent at delivery |
| `testimonial-ask.md` | How to ask so you actually get one |
| `seo-pricing-page.md` | Productized service pricing structure |
| `ai-ops-install.md` | Higher-ticket automation offer |
| `LOVABLE-PROMPTS.md` | Prompts for generating client sites fast |
| `30-day-agency-ops-checklist.html` | A real 14-page lead magnet. Editable HTML, prints to PDF. Rebrand the fonts and colors and it is yours |
| `white-label-reseller-onepager.html` | One-page service pitch |

**On the lead magnet:** gated downloads work. Someone trades an email for the
checklist, then gets a nurture sequence. The document is styled to a brand that
is not yours, so change the fonts and colors first. The content structure is the
valuable part.

**On the recurring revenue:** the single highest-leverage thing in this folder is
the care plan pitch. One-off projects mean starting every month at zero. Monthly
retainers compound. Pitch it at delivery, when the work is fresh and they are
happy, not three months later.
